Link Opportunities — Strategy Notes

🎯 JB Content Hub — High internal linking potential

The JB content cluster (Train to JB, JB Food Guide, Mall guides, Go Kart JB, Breakfast in JB) collectively drives the most non-branded traffic. These pages currently lack a proper hub-and-spoke internal linking structure. A "JB Travel Hub" index page with contextual links to all JB articles would distribute PageRank more efficiently and could improve positions on individual articles.

🌐 China Payment Articles — External link reclamation

The WeChat Pay and Alipay articles hold positions 7–9 on 1M+ combined impressions. At this position, external links are critical for breaking into the top 5. These topics have strong link potential from expat blogs, travel forums (Reddit r/singapore, r/solotravel), and China travel guide sites. A targeted outreach to 5–10 relevant sites could yield 2–3 position improvements.

📰 PR/Media — YouTrip brand mentions without links

Brand name "YouTrip" generates 28K+ clicks from branded queries. Any unlinked brand mentions in media or blogs represent reclamation opportunities. Run a Semrush brand mention audit (requires API access) to identify and request links from existing mentions of YouTrip in SG/MY travel content.

✍️ August roadmap: Canonical audit

August's planned roadmap initiative is the canonical audit. The indexing findings this month (5/6 key pages unknown to Google) are directly related. The canonical audit should start with the new URL structure issue — confirming self-canonicals on new pages and implementing proper 301s from old /blog/ URLs. See Indexing page for the full fix checklist.

Recovering Semrush Data

To pull Semrush data manually, run the following from a terminal with unrestricted network access:

curl "https://api.semrush.com/?type=domain_overview&key=API_KEY&export_columns=Dn,Rk,Or,Ot,Oc,Ad,At,Ac&domain=you.co&database=sg"

curl "https://api.semrush.com/analytics/v1/?action=report&type=backlinks_overview&key=API_KEY&target=you.co&target_type=root_domain&export_columns=ascore,total,domains_num,urls_num,follows_num,nofollows_num"

The next scheduled audit will attempt to pull this data again. If the proxy policy changes, it will succeed automatically.
