Desktop TBT: SGD-to-JPY (4,060ms) and Exchange Rates (2,980ms) — likely rate widget JS

The exchange rate widget on these pages appears to be executing significant JavaScript that blocks the main thread. Recommended fix: load the live rate widget asynchronously (defer or dynamic import) so it doesn't block interactivity. Target: TBT <200ms. This is the same class of issue as the TBT problem on "About YouTrip" flagged in March (1,120ms then, now 680ms — partial improvement).

Fix Recommendations
🔴 P0 — Homepage hero image lazy-loading
Remove loading="lazy" from the hero/LCP image. Add fetchpriority="high" and preload hint: <link rel="preload" as="image" href="hero.webp">. Estimated LCP improvement: 15–20s → 2–3s. March ticket still open.
🔴 P0 — Convert hero images to WebP and size correctly
Homepage hero is likely a large PNG/JPEG. Convert to WebP with srcset for mobile/desktop variants. Serve 400px wide on mobile. This compounds with the lazy-loading fix.
🟡 P1 — Defer exchange rate widget JS (SGD-JPY, Exchange Rates pages)
Move the live rate widget to a dynamic import() or load it via requestIdleCallback. Desktop TBT 4,060ms → target <200ms. Affects interactivity signals.
🟡 P1 — Article page LCP: lazy hero image pattern
Travel Insurance (5.6s), About YouTrip (6.0s), Exchange Rates (10.6s) all show the same LCP pattern — hero image is lazy. Apply the same preload fix as homepage across article template.
