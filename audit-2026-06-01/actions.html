P0 — Critical (Fix within 1 week)

P0 Diagnose and fix indexing for 5 unknown key pages

Pages affected: /sgd-to-yen/, /travel-insurance-singapore/, /youtrip-exchange-rates/, /everything-you-need-to-know-about-youtrip/, /singapore-public-holiday-2026/

Data: GSC URL Inspection returned "URL is unknown to Google" for all 5 pages. Only the homepage is confirmed indexed.

Steps: (1) Check robots.txt for disallow rules. (2) Inspect each page's meta robots tag for noindex. (3) Verify URLs are in sitemap. (4) Request indexing in GSC. (5) Confirm canonical tags are self-referential.

Effort: Low · Impact: Critical — these pages cannot rank if not indexed.

P0 Investigate Homepage mobile LCP of 26.9 seconds

Page: https://www.you.co/sg/ · Mobile Perf Score: 42/100

Data: LCP 26.9s (Good threshold: 2.5s). This is 10x above the "Poor" threshold. FCP 6.0s. TBT 540ms.

Steps: (1) Run Lighthouse trace to identify LCP element. (2) Check hero image size and format (WebP?). (3) Audit third-party scripts (chat, analytics, ads). (4) Measure server TTFB. (5) Check for render-blocking resources. (6) Implement lazy loading for below-fold images.

Effort: Medium · Impact: Critical — Page Experience ranking signal. CWV failure can suppress rankings.

P0 Fix Semrush API IP allowlist to restore link data

Issue: API returned "Host not in allowlist" — domain authority and backlink data completely unavailable.

Steps: Log in to Semrush → Account → API Access → IP Restrictions. Whitelist the audit server IP or remove IP restriction for automated reporting use cases.

Effort: Low · Impact: High — Without this, monthly audits are missing a key data source.
